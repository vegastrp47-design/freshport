The navy status badge and the outlined chips from the website.

- **Badge** (`fp-badge`): a pill in `action` with a leading dot, Prompt Medium 12.5px, uppercase. Use it for one status, e.g. ARRIVING SOON.
- **Chip** (`fp-chip`): an outlined pill for short facts such as the origin, how to reserve or the markets supplied. Chips wrap in a row (`fp-chips`). On navy they drop the white fill.

The consumer provides short text, three to five words.
