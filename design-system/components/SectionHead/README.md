Every website section opens with an eyebrow, a DM Serif Display heading with its Thai line underneath, and an optional lede.

Markup: `fp-head` holds `fp-eyebrow` (uppercase, `eyebrow` colour), an `h2.fp-h2` with a `span.fp-th` inside for the Thai line (Prompt Light 18px, `ink-muted`), and `p.fp-lede` (at most 58ch). Use `fp-head--center` on the partners and steps sections. The consumer provides the English heading, the Thai line and the eyebrow. The heading stays one colour on the website.
