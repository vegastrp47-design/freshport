Pill buttons from the website, 50px tall (42px small), Prompt Medium 15.5px.

- **Navy** (`fp-btn fp-btn--navy`): the one main action on light grounds, e.g. 'Reserve on LINE'. It is the `action` fill with `on-action` text.
- **Outline** (`fp-btn--outline`): the second action beside a navy button.
- **White and outline-white** (`fp-btn--white`, `fp-btn--outline-white`): the same pair on navy grounds (hero, visit block).
- **Text link** (`fp-link`): a link with an underline and an arrow, for 'See what's new on Instagram' and 'Get directions'.
- **Icon button** (`fp-iconbtn`): 42px round, for social icons in the navy header.

The consumer provides the label and the link, plus an optional leading icon (the LINE icon for chat actions). Keep to at most two buttons per group. On hover a button lifts 2px and takes `shadow-hover`, and focus shows a 3px `focus-ring`.
