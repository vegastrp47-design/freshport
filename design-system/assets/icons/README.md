These are the 14 line icons from the website (`snippets/fp-icon.liquid`):

- **Icons:** ship, leaf, tag, basket, globe, pin, clock, instagram, facebook, chat, store, bag, line and arrow.
- **Drawing:** a 24 × 24 grid, a 1.8 stroke, round caps and joins, no fill.
- **Colour:** the files are stroked midnight blue #112331, because an `<img>` can't recolour them. In code, inline the path with `stroke="currentColor"`, as the site and the component bundle do.
- **Placement:** set them at 22px inside 44 to 46px tiles, 18px in buttons and 14px beside small text.
