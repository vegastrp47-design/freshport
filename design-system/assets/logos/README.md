These are the official Fresh Port logos as exact vectors converted from the Illustrator PDFs (`Fresh Port copy.pdf`, `Fresh Port (แบบวงกลม) copy.pdf`). Each file is single-ink, so pick the file by the ground it sits on:

- **`-primary` files are the primary logo:** a white ship and wordmark on a `midnight-blue` (#112331) tile. Use them wherever the logo stands alone.
- **`-navy` files are filled #112331 with a transparent background.** Use them on white and light grounds, where the white logo would be hard to see.
- **`-white` files are filled #ffffff with a transparent background.** Use them on midnight blue or dark photos.

Clear space (the height of the round sun) is built into every file. There are no gold or other colour versions. The README's Logo section has the minimum sizes and the don'ts.
